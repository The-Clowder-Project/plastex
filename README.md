# Gerby (for Clowder)
This is a fork of [Gerby](https://github.com/gerby-project/plastex), which is itself a fork of [plasTeX](https://github.com/plastex/plastex).

It is built specifically to accomodate [Clowder's](https://www.clowderproject.com/) needs.

## Info
Some of the files changed:
- Jinja2s templates on ``plasTeX/Renderers/Gerby/*.jinja2s``
- ``plasTeX/Renderers/Gerby/__init__.py``
- ``plasTeX/Base/LaTeX/GerbyCommands.py``
